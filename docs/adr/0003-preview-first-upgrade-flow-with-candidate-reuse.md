# Preview-first upgrade flow with candidate reuse

Status: accepted

Users will reach paid Starter and Pro packages from a Free Preview result rather than choosing a paid package before seeing value. The Free Preview uses the same underlying generation quality as paid candidates but is watermarked and restricted; when the user upgrades without changing style, that preview is promoted to candidate #1 so paid generation only fills the remaining candidate slots, reducing provider cost while preserving a clear outcome-package purchase path.
