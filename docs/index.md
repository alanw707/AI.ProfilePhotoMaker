# Project Documentation Index

## Project Overview
- **Type:** monorepo with 2 parts
- **Primary Language:** C# (.NET) + TypeScript
- **Architecture:** API (layered web API) + UI (Angular standalone)

## Quick Reference

### API (api)
- **Type:** backend
- **Tech Stack:** ASP.NET Core (.NET 8), EF Core, SQL Server
- **Root:** `AI.ProfilePhotoMaker.API`

### UI (ui)
- **Type:** web
- **Tech Stack:** Angular 19, TypeScript, RxJS
- **Root:** `AI.ProfilePhotoMaker.UI`
