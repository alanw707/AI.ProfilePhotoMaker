# Security & Trust (Draft)

Last updated: 2025-12-19  
Status: Published in UI (legal review pending).

## 1. Security Controls
- Access controls and authentication safeguards to protect accounts.
- Encrypted transport (HTTPS) for data in transit.
- Input validation and file safety checks for uploads.
- Operational logging for security and reliability monitoring.

## 2. Data Protection
Retention limits apply to uploaded and generated images. Users can delete photos, models, or their account.

## 3. Third-Party Providers
We use trusted providers for AI processing and payments. See the Subprocessors list for details.

## 4. Incident Reporting
If you believe your account or data is at risk, contact `security@aiprofilephotomaker.com`.

## 5. Responsible Disclosure
We welcome responsible security reports with reproduction steps and relevant context.
