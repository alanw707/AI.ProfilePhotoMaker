# 09: Compare U.S. markets through an accessible heatmap and table

## Parent

https://github.com/alanw707/AI.ProfilePhotoMaker/issues/376

## What to build

The user explores national, state and metro evidence, compares up to three compatible places, and explicitly saves a location preference to the career goal.

## Acceptance criteria

- [ ] Use validated source-compatible U.S. geography boundaries/crosswalks and include Alaska/Hawaii and any other covered areas; disclose actual coverage.
- [ ] Power map and sortable keyboard-accessible table from the same bounded query and evidence snapshot; mobile defaults to a searchable list.
- [ ] Offer distinct supported wage, employment concentration and projection metrics; unsupported metrics are disabled with explanation.
- [ ] Suppressed/missing values are labeled/patterned separately from low values; legend exposes units, period and measure.
- [ ] Compare up to three places without summing overlapping state/metro counts; save-to-goal requires explicit confirmation and version precondition.
- [ ] Test map/table parity, keyboard/mobile selection, missing cells, geography mismatch, filter persistence and contextual explanation.

## Blocked by

- https://github.com/alanw707/AI.ProfilePhotoMaker/issues/382 — Produce a sourced national and local career market brief

## Delivery boundary

Keep this slice demoable or independently verifiable. Extend existing API/browser testing seams and preserve unrelated work. Use synthetic fixtures, not reference-screenshot personal data. Every private entity must participate in ownership, export/deletion and retention rules. No production rollout or paid service purchase is authorized by this issue alone.
