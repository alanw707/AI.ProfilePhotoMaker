# 11: Create a target-specific career roadmap

## Parent

https://github.com/alanw707/AI.ProfilePhotoMaker/issues/376

## What to build

After selecting a target role, a user reviews realistic path alternatives and accepts an actionable roadmap grounded in their profile, market evidence and available effort.

## Acceptance criteria

- [ ] Generate distinct closest-fit, higher-ambition and steadier-transition options only when evidence supports them; fewer alternatives are valid.
- [ ] Record pinned target/profile/report versions, rationale, assumptions and missing evidence; timelines are scenarios, not guaranteed promotions.
- [ ] Show this week's concrete output plus 30/60/90-day milestones, editable effort and valid task dependencies.
- [ ] User selects/accepts the path explicitly; no silent goal change, credential invention, salary uplift or paid-course obligation.
- [ ] Persist and reload a private versioned roadmap, with stale evidence indicators and a readable assumptions section.
- [ ] Test low time availability, no supported alternative, ambiguous goal, cyclic task proposals, sparse pay fallback and accessible selection flow.
