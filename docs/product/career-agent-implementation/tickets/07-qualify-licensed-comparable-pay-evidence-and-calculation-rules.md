# 07: Qualify licensed comparable-pay evidence and calculation rules

## Parent

https://github.com/alanw707/AI.ProfilePhotoMaker/issues/376

## What to build

Deliver a reproducible evidence qualification report establishing whether a licensed source can support personalized advertised-pay analysis. This is a verifiable discovery slice, not an invented production integration.

## Acceptance criteria

- [ ] Evaluate candidate posting providers' U.S. coverage, explicit level/location/pay attributes, remote restrictions, deduplication IDs, freshness, commercial display/cache/retention rights and pricing.
- [ ] Do not purchase or accept new paid terms; identify any necessary approval or credentials and record pass/fail gates.
- [ ] Using lawfully accessible observations, reproduce covered and sparse cases across at least three occupation families and multiple geographies; retain permissible evidence or hashes/source references.
- [ ] Validate the proposed observed-pay interval, percentile interpolation, known-basis normalization, 90-day lookback and starting floor of 10 independent observations/5 employers; document calibrated rule changes and employer concentration.
- [ ] Report excluded observations, sensitivity, missing attributes and benchmark fallback; no model-generated salary rows, guessed seniority or experience multiplier.
- [ ] Produce a selected-provider decision and sanitized fixtures with versioned expected results; if coverage/rights fail, explicitly block personalized production release rather than labeling benchmarks personalized.

## Blocked by

None (can start immediately).

## Delivery boundary

Keep this slice demoable or independently verifiable. Extend existing API/browser testing seams and preserve unrelated work. Use synthetic fixtures, not reference-screenshot personal data. Every private entity must participate in ownership, export/deletion and retention rules. No production rollout or paid service purchase is authorized by this issue alone.
