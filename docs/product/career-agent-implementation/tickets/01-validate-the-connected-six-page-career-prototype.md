# 01: Validate the connected six-page career prototype

## Parent

https://github.com/alanw707/AI.ProfilePhotoMaker/issues/376

## What to build

Use Impeccable to produce a connected, clearly synthetic prototype for all six approved pages and the persistent contextual assistant. Keep the existing name/domain and photo entry. Validate the professional's core journey before expanding the backend.

## Acceptance criteria

- [ ] Run Impeccable visual-direction selection; preserve branding and record approved career visual rules separately from the photo-workspace theme.
- [ ] Connect Agent, Profile, Analytics, Heatmap, Roadmaps and Materials, including mobile assistant sheet, navigation and focus/scroll restoration.
- [ ] Demonstrate empty, working, needs-input, partial, stale, error and quota states without claiming real backend capability.
- [ ] Show source definitions, uncertainty, profile edit review and optional photos; avoid exact personal-worth numbers or a global career grade.
- [ ] Observe representative target users correcting a fact, explaining a pay range, comparing markets, editing a roadmap and preparing materials without buying photos; record failures and resolve launch-blocking misunderstandings.
- [ ] Check narrow mobile, desktop, keyboard, visible focus, 200% zoom, contrast and reduced motion; attach review evidence and handoff decisions.

## Blocked by

None (can start immediately).

## Delivery boundary

Keep this slice demoable or independently verifiable. Extend existing API/browser testing seams and preserve unrelated work. Use synthetic fixtures, not reference-screenshot personal data. Every private entity must participate in ownership, export/deletion and retention rules. No production rollout or paid service purchase is authorized by this issue alone.
