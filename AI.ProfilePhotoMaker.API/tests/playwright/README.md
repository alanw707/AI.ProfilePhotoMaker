# Style Preview Image Testing Framework

Comprehensive browser-based testing for style preview image accessibility, loading, and integration validation.

## Overview

This testing framework validates style preview images in both **current state** (404 validation) and **post-upload state** (200 OK with valid images). The framework automatically adapts based on Azure Storage credential availability.

## Quick Start

### 1. Setup Dependencies
```bash
cd tests/playwright
npm install
npm run install-browsers
```

### 2. Configure Azure Storage (Optional)
```bash
# Automated setup (requires Azure CLI)
./scripts/setup-credentials.sh

# Or manually create .env file
cp .env.template .env
# Edit .env with your credentials
```

### 3. Run Tests
```bash
# All tests (adapts to credential availability)
npm test

# Pre-upload validation only (current 404 state)
npm run test:current-state

# Post-upload verification (requires credentials)
npm run test:post-upload

# Integration tests
npm run test:integration

# Performance tests
npm run test:performance
```

## Test Modes

### Pre-Upload Mode (Default)
- **Triggers**: No Azure Storage credentials configured
- **Tests**: Validates all style preview URLs return 404 (expected current state)
- **Purpose**: Confirms baseline state before image upload

### Mixed Mode (Full Testing)
- **Triggers**: Valid Azure Storage credentials available
- **Tests**: Both 404 validation and 200 OK verification
- **Purpose**: Comprehensive validation of all scenarios

## Troubleshooting

### No Credentials Configured
```
⚠️ No Azure Storage credentials configured
💡 Run scripts/setup-credentials.sh to configure credentials
💡 Or manually create .env file with AZURE_STORAGE_CONNECTION_STRING
```

### Connection Issues
```
❌ Azure Storage connection test failed
- Check account key validity
- Verify container 'style-previews' exists
- Ensure public read access is configured
```

### Image Load Failures
```
❌ Images failed to load
- Verify images have been uploaded to Azure Storage
- Check blob public access permissions
- Test individual URLs in browser
```

### Performance Issues
```
⚠️ Slow load times detected
- Check network connectivity
- Verify Azure Storage geo-location
- Consider CDN configuration
```

## Architecture

### Test Framework Components
- **Global Setup**: Configuration validation and connectivity testing
- **Test Data**: 21 style preview test cases with metadata
- **Test Helpers**: Image loading, performance measurement, validation utilities
- **Azure Config**: Credential management and environment configuration
- **Credential Scripts**: Automated Azure Storage setup

### Design Principles
- **Adaptive Testing**: Tests adapt based on credential availability
- **Evidence-Based**: All assertions backed by measurable data
- **Fail-Safe**: Graceful handling of missing credentials or network issues
- **Comprehensive Coverage**: Tests all critical paths and edge cases
- **Performance-Focused**: Continuous monitoring of load times and optimization
