Issues and specs are tracked in GitHub Issues for `alanw707/AI.ProfilePhotoMaker` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
