## Tracking + Reporting Loop

### UTM conventions
Base URL: https://app.aiprofilephotomaker.com/pricing

Use these parameters for each link:
- utm_source: linkedin | instagram | x | facebook
- utm_medium: social (organic) | paid-social (boosted)
- utm_campaign: social-quick-win-2025-12
- utm_content: short creative id (ex: before-after-01, testimonial-amelia)
- utm_term: optional persona tag (ex: job-seeker, freelancer)

### Homepage test UTMs
If testing homepage, use the same UTM structure with the base URL `https://app.aiprofilephotomaker.com/` and append `-home` to `utm_content`.

### Example URLs
- https://app.aiprofilephotomaker.com/pricing?utm_source=linkedin&utm_medium=social&utm_campaign=social-quick-win-2025-12&utm_content=testimonial-amelia
- https://app.aiprofilephotomaker.com/pricing?utm_source=instagram&utm_medium=paid-social&utm_campaign=social-quick-win-2025-12&utm_content=before-after-01

### Daily check
- Clicks by platform and post type
- CTR and conversion rate
- If CR weak after day 3, test homepage vs /pricing (see trigger below)

### Conversion goals and triggers
- Primary conversion: purchase of a credit package.
- Leading indicator: checkout started.
- Targets to start: CTR >= 1%, checkout-start rate >= 3%, purchase rate >= 1.5%.
- "Weak conversions" trigger: purchase rate < 1% or checkout-start < 2% after day 3.

### Fallback tracking (if pixel/Insight Tag inactive)
- Use GA4 page and purchase events with UTMs preserved.
- Export checkout/purchase reports weekly and segment by UTM parameters.
- Track top-performing creatives manually in a simple sheet if needed.

### Weekly review
- Identify top 2 performing creatives
- Re-boost winners, pause underperformers
- Update copy if CTR < 1%
