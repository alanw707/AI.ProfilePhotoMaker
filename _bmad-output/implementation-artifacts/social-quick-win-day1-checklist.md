# Day 1 Launch Checklist (Social Quick-Win)

## Prep (60-90 min)
- [ ] Confirm landing page: https://app.aiprofilephotomaker.com/pricing
- [ ] Confirm conversion event (Purchase/Checkout) or decide traffic objective
- [ ] Create UTM templates (organic + paid)
- [ ] Pull 2 testimonials with permission or anonymize
- [ ] Create 2 assets: promise card + testimonial card
- [ ] Set posting times for today (local timezone)

## Post Setup (30-45 min)
- [ ] Draft 2-3 posts (LinkedIn + IG + X)
- [ ] Add UTM links to each post
- [ ] Schedule posts for peak times

## Paid Boost (Optional, 20-30 min)
- [ ] If boosting: set objective to Conversions (or Traffic if no pixel)
- [ ] Set budget ($10-$25/day)
- [ ] Target job seekers + LinkedIn interest (IG/FB)
- [ ] Use paid UTMs: utm_medium=paid-social

## Monitoring (10 min)
- [ ] Verify links resolve and UTMs appear in analytics
- [ ] Note baseline CTR and conversions
- [ ] Watch comments/DMs for quick replies
