# AI Profile Photo Maker - Project Purpose

## Overview
AI Profile Photo Maker is a modern web application for creating professional AI-generated profile photos using Replicate's AI models. The application allows users to upload selfies which are used to train a custom AI model through Replicate.com's FLUX API, then generates high-quality professional profile photos in various styles.

## Key Features
- **User Authentication**: Secure registration and login with social auth (Google, Facebook)
- **Image Upload**: Upload up to 10 selfies for AI model training
- **Style Selection**: Choose from multiple professional photo styles
- **AI Processing**: Custom model training and image generation via Replicate API
- **Results Gallery**: View, download, and manage generated photos
- **Subscription Plans**: Tiered access features based on subscription level
- **Payment Integration**: Stripe integration for subscription management

## Business Model
- Subscription-based service with different tiers
- AI-powered professional photo generation
- Cloud storage for user images and results
- Multi-style photo generation options

## Target Audience
Professionals and individuals seeking high-quality AI-generated profile photos for social media, LinkedIn, resumes, and professional use.
